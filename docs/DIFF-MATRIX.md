## 二、重名率实测
- 同名/同构（7）：看板=看板；病情整理=病情整理；我的瘤·分级与基因≈我的分期；双线随访·指标系列≈检查与指标；病情一图秀=病情一图秀；临床与试验·匹配≈治疗历程+临床研究（合并同构）；就诊问题清单≈复诊准备。
- 差异化（4）：注射与周期（cervical/breast 均无）；腹泻与饮食（≈营养支持仅换词？否——命名主题由"营养支持"改为"腹泻与饮食"，非病种词替换）；慢病心晴（同上，心理支持的 NET 慢病化重命名）；收藏回顾（cervical 无一级页）。
- **重名率 = 7/11 ≈ 63.6% ≤ 70% 目标 ✅**（v0 草案曾 77.8% 超标，已重构命名）。
