## 4. 差异评价

### G1 S2 一图秀验收合同不完整
- 现象：原型有折线和指标选择草案，但缺 C1–C12 多项（单点/空态完整状态、点回源、治疗 lane、aria 状态、窄屏、固定详情等）。
- 证据：`docs/ONE-CHART-SPEC.md` R1–R12 与 C1–C12；`PROTOTYPE-REVIEW.md` 一图秀行。
- 影响：实现者可能仅做“看起来有图”，多指标范围、病灶可比性和键盘状态没有保证。
- 处置：P1 进入 C1–C12 实测与可执行脚本后再申请 G2。

### G2 S5 临床试验结果仍为模拟
- 现象：试验卡包含匹配指数，但 SQLite、外部检索、更新/失败状态未实现。
- 证据：`prototypes/v0.1/demo-data.js` `trials` 数组 SIM-NET-001…003；页面显式写“模拟条目”。
- 影响：不得把示例匹配指数或条目当成患者真实匹配结果。
- 处置：M4 建立来源 manifest/jsonl/sqlite 与失败状态后，再核对 AI 匹配合同。

### W1 患者语言目前不是一手引语
- 现象：所有患者句均为改写占位，0 访谈。
- 证据：`USER-RESEARCH.md` §证据分层；各原型页脚注“改写占位”。
- 影响：不能作为需求频率或偏好结论。
- 处置：持续招募访谈；验证前保留改写标记。
