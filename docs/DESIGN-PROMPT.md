## 我代表谁
NET（神经内分泌和肾上腺肿瘤，NCCN #67，含 GEP-NETs 与嗜铬细胞瘤/副神经节瘤挂靠）**患者本人**为默认服务主体；家属代记为次要主体。随访医生是资料的**读者**，产品不做判读、不代医生下分级/治疗结论。

## 取舍标准
1. 患者原话优先于医生任务：每条功能线挂一句患者原话；0 访谈阶段如实声明，改写句不冒充一手引语。
2. 数据只有一个来源：一次录入（分级档案/生化/影像/注射事件）在指标卡、一图秀、临床、摘要间复用 ID/版本。
3. 医学约束转字段：Ki-67、CgA/5-HIAA、影像、基因（MEN1/VHL/NF1/RET/SDHx）全部三态记录（原文/未测/待出），**分级判定归医生，产品只引用**。
4. 原型是唯一视觉基准：开发版逐字符对齐。
5. 没实测不写"通过"；约定必须有测试与语境栏。

## NET 专属设计要点
- **双线随访**：生化线（CgA/5-HIAA/激素）与影像线（CT/MRI/SRI/68Ga-PET）并行，趋势比单次重要；只呈现不判读。
- **慢病化治疗**：SSA（奥曲肽 LAR/兰瑞肽）按月/季注射是长程事件，与周期化疗不同形态；PRRT（177Lu-DOTATATE）四周期独立轨道。
- **指标系列化**（用户补充 1）：指标卡围绕疾病相关指标**系列**构建，有序、分系列，动态 3D 反转展现背面内容 + 趋势折线（smoothPath 用 Fritsch–Carlson）。
- **一图秀指标选择窗口**（用户补充 2）：一图秀需增加指标选择窗口，可挑选进入一图的指标。
- **临床试验匹配**（用户补充 3）：基因/病理 IHC 维护建档 → 搜索或 AI 协助匹配 → 查询自带 sqlite + 外部工具 → 匹配结果带匹配指数与格式（参考胆道癌临床展现图 prototypes/v0.2）。
- **肾上腺亚群**：嗜铬细胞瘤的 MN/CNs 激素线与血压日记为独立系列，不并入 NET 主趋势。
