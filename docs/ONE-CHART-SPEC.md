# 小泌宝一图秀与指标卡规格 v0.2

> 通用规则见 `docs/16-ONE-CHART-SPEC.md`。当前为原型实现规格，不代表 C1–C12 已实测通过。原型入口：`prototypes/v0.1/index.html`；包/界面版本：0.1.3。数据均为模拟值。

## 一图秀布局与操作

- 左栏顺序：时间范围 chips（3/6/12 个月、全部）→ 按指标系列分组的复选框（勾选即时更新）→ 显示开关（末点数值、参考网格）。
- 趋势区：每项指标单独一行和一条折线；每条线独立按**该指标全期 min/max**缩放，不共用 Y 轴，不暗示指标间可比。
- 图例：每项显示名称、全期 min–max 与单位；时间范围筛选只决定可见点，不重算全期缩放范围。
- 点位：可点击/键盘聚焦；固定详情显示指标、原始值、单位、日期和该次记录来源；更改时间范围后仍保留详情文字，但若点不在可见窗口，图上不显示 pin ring。
- 同屏最多 4 项；试图勾选第 5 项时明确提示，非静默吞掉。
- 一个指标随时间范围筛选后没有点时，显示明确空态；报告分类不进入数值趋势。

## 指标卡合同

- 固定卡片尺寸，原位 3D 翻转，不插入扩展内容、不改变周围布局。
- 正面依次显示：分类色点 + 分类名称、当前值 + 单位、较前次变化箭头 + 绝对差、记录数、最近日期。
- 背面显示：同源历史 sparkline、首末端数值与日期、最近记录来源。
- `aria-pressed` 表达独立翻转状态；卡片尺寸、其他卡状态、滚动位置不得随翻转改变。
- 派生变化只显示于视图，不成为事实记录；零值/缺值不伪装为 0。
