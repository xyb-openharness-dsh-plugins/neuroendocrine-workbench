# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：NET 患者本人（默认）与家属；随访医生仅引用不代判

场景：分化良好 NET 长程管理：确诊分级（Ki-67/IHC/基因）→ 治疗线（SSA/PRRT/靶向）→ 生化+影像双线随访

核心流程：
1. 建档：录入分级档案（Ki-67/分化/IHC 原文）与基因检测结果
2. 记录：逐次录入 CgA/5-HIAA 等生化、影像报告与 SSA 注射事件
3. 回顾：分系列指标卡 + 趋势折线看长期走势，生成就诊问题清单；按基因/病理匹配临床试验

完成结果：患者能回答“我现在是什么分级、指标趋势如何、下一次该查什么、有没有适合我的试验”

初始布局选择：business-first

先读取 docs/DESIGN-PROMPT.md，对齐设计者与研究/取舍原则，再逐项完善SPEC。待补：确认来源、Desktop 版本/平台、原型 hash、当前授权与离线/联网边界。

## NET 病种背景（v0.1，医学口径 M1 核验）
- 范围：神经内分泌和肾上腺肿瘤（NCCN #67，2.2025），含 GEP-NETs（罕见病 #31 挂靠）与嗜铬细胞瘤/副神经节瘤（罕见病 #60 挂靠）；以分化良好 NET 长程管理为主线，肾上腺亚群独立激素语境。
- 关键医学概念（转字段，判定归医生）：Ki-67 指数与分化分级（G1/G2/G3）、IHC 标志物（CgA/Syn 等）、生化标志物（CgA/5-HIAA/NSE）、影像（CT/MRI/SRI/68Ga-PET）、基因（MEN1/VHL/NF1/RET/SDHx，VUS 三态）、治疗线（SSA 长程注射、PRRT 四周期、靶向/化疗、手术）。
- 差异化：与家族已有仓（消化族/胸部族/血液族）相比，NET 独有"生化+影像双线慢病化随访 + SSA 注射慢病形态 + PRRT 核素治疗 + 基因家系分层试验匹配"组合，详见 docs/SCENARIOS.md 与 DIFF-MATRIX（M1）。
