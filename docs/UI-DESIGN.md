# 小泌宝 UI 设计记录 v0.1

状态：原型草案；无用户视觉确认。依据 SPEC v0.2、INTERACTION-DESIGN v1、DEV-REQUIREMENTS 与 NET 患者证据分层。

## 信息架构
一级页：看板、病情整理、我的瘤·分级与基因、双线随访·指标系列、病情一图秀、注射与周期、临床与试验·匹配、腹泻与饮食、慢病心晴、就诊问题清单、收藏回顾；所有业务页顶栏右侧具名“设置”。页面保持患者任务，不用医生工作流命名。

## 视觉草案
- 情绪方向：清晰、温和、低刺激；纸白/鼠尾草绿为主，橙色仅标记待核/模拟。
- 字体：DM Sans + Noto Sans SC；正文默认 14px；桌面最小可读 12px，后续按要求升到 ≥12.5px。
- 主容器：看板/指标用 `minmax(0,1fr)` 网格；面板宽 25–45% 目标，原型 AI 区当前固定宽度，不是真正 splitter。
- 指标卡 v0.1.3：固定尺寸原位 3D 翻转；正面分类色点、当前值、较前次变化箭头、记录数；背面 sparkline、首末端值/日期和来源。代码已写，尺寸不变、独立状态、键盘/读屏与减少动效尚未实测。
- 一图秀 v0.1.3：左栏时间范围 chips、按系列指标即时勾选、末点值/网格开关；每线独立按全期范围缩放，图例显示全期区间；点选 pin 显示数值和来源。代码已写，日期筛选、点选、来源显示和窄宽未在浏览器实测。
- 治疗线：原生 `<details>/<summary>` 默认收起，展开五块（方案/指标趋势/影像/副作用/心理营养），`beforeprint` 展开再恢复；需实测后确认。
- 窄宽：1180/900/600 断点；900 以下 AI 面板变覆盖层、导航横向。尚未实测 390px 溢出与大字。
- 减少动效：声明 `prefers-reduced-motion`，尚未核验翻转终态和图表状态。

## AI 与隐私（v0.1.5）

- 顶栏是唯一“收起 AI 对话 / 打开 AI 对话”入口，控制右侧状态栏显示；隐藏不清空草稿。没有浮动重复入口或面板内第二个关闭按钮。HTML 状态稿明确标注“宿主模拟 · 非真实 DSH 会话”，不代表原生服务已连接。
- 每个一级页面在页头提供“和 AI 讨论”。按当前页面生成提示词和页面摘要，摘要标明模拟数据/核对状态/缺项；情绪页不携带私密记录，不包含本机路径或凭据。
- 宿主内嵌时按 34 号发送 `neuroendocrine:agent-draft`，`send:true`，由真实宿主桥按源窗口、origin、session owner 与原生草稿状态校验后送入原生会话。当前 `lib/client.js` 尚无此桥，故实机接线状态未实现；独立原型仅填本地草稿并提示未发送。
- 原型 AI 面板开合和逐页按钮尚未完成浏览器直接交互验收；宿主五态、ensureSession、防重复会话、草稿冲突和 native submit 均未验证。见 `docs/AGENT-PANE-DESIGN.md` 与 `docs/PROTOTYPE-REVIEW.md`。
