# 四核心模块（NET 版 v0.1）

状态：M0 草案；M1 SPEC 定稿后逐项给功能 ID 与验收。四核心继承家族通用能力（病情整理/指标检测/一图秀/临床治疗及试验），此处写 NET 特有形态。

## 1. 病情整理（我的瘤）
- 分级档案：Ki-67 数值、分化分级（G1/G2/G3）、IHC 标志物（CgA/Syn/CD56 等）原文三态记录；原发部位（胃/胰/肠/肺/肾上腺/不明原发）。
- 基因档案：MEN1/VHL/NF1/RET/SDHx，含 VUS/未检出/未测三态，家庭系线索（遗传咨询语境，不代判）。
- 判定归医生：产品只引用报告原文 + 提供语境栏解释名词。

## 2. 指标检测（分系列指标卡）
- 系列：生化系（CgA/5-HIAA/NSE）、影像系（CT/MRI/SRI/68Ga-PET 病灶测量与描述）、激素系（肾上腺亚群 MN/CNs/皮质醇等）。
- 卡片：正面当前值+语境栏，**动态 3D 反转**看背面详情（系列说明/单位/参考区间来源/历史摘要），趋势折线 smoothPath（Fritsch–Carlson）。
- 硬纪律：分类不进趋势；无诊断/risk_level 类判定列；ORDER BY rowid；显式 null。

## 3. 一图秀（独立病情一图秀）
- 单份资料复用 ID；**指标选择窗口**（用户补充 2）可勾选进入一图的指标与系列。
- SVG 根 class="chart"；输出可导出。

## 4. 临床治疗与试验
- 治疗事件轨道：SSA 注射（药物/剂量/周期/部位轮换）、PRRT 4 周期、手术、其他靶向/化疗线。
- 临床研究真实状态流：个人病理/IHC/基因/治疗线字段准备 → 数据源状态（本地 SQLite、外部注册平台/工具分别列出接入状态与最近查询时间）→ 患者显式发起检索 → 结果按来源展示研究编号、地区/状态、更新时间、条件原文与匹配依据 → 患者自行关注并带去就诊讨论。
- 未发起查询显示“未查过”；来源未接入显示“未接入”；查询失败显示失败来源与时间；已查询但无结果才可显示“本次无结果”。不得用空列表/模拟条目伪装零命中。
- 当前 M2 原型不含真实试验结果或匹配分数。SQLite/外部工具须由 M4 建 fetch 四件套与 manifest/jsonl/sqlite 后接入；用户提出的匹配指数仍为产品需求候选，但不能以模拟分数冒充真实结果。须先定义字段权重、缺失值处理、版本、可解释文案和验证办法，未验证前不对患者展示。
- 试验关注/来源对照和 private 三出口代码级过滤仅在真实数据链路落地后验收；AI 可帮患者整理查询条件，不生成研究条目、不判断入组或适配资格。
- AI 按钮走 xxx:agent-draft 携带提示词+病情上下文。

## 支撑线（一期保留栏目，按用户任务推导）
- 营养（腹泻/脂肪泻语境）、心理（慢病疲劳）、全程安排（随访日历）、收藏回顾、Agent、真实格式导出——M1 定深度。
